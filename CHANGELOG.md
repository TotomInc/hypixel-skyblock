# Changelog

## 0.1.0

First public release.

- Client-only Fabric helper for Minecraft 26.2
- Detects The End from the Hypixel SkyBlock sidebar
- Confirms Ender Nodes from portal and witch particles, including far unloaded chunks
- Through-wall cyan frames around confirmed nodes
- Drops nodes that go silent or whose block is gone
- `/endernodes` status, toggle, and debug commands
